RENTA CAR EXPRESS - PROYECTO WINDOWS FORMS

Contenido:
- RentaCarExpress.csproj: proyecto para Visual Studio.
- Program.cs: punto de entrada.
- frmAlquiler.cs: lógica y eventos del formulario.
- frmAlquiler.Designer.cs: interfaz gráfica y controles.

COMO ABRIR:
1. Extrae la carpeta RentaCarExpress.
2. Abre RentaCarExpress.csproj con Visual Studio 2022.
3. Si Visual Studio solicita restaurar paquetes, acepta.
4. Ejecuta con F5.

Requisitos:
- Windows
- Visual Studio 2022
- .NET 8 SDK con la carga de trabajo Desarrollo de escritorio de .NET.
